# CineQuiz 🍿🎬

> Test your filmy superpowers! A responsive, interactive Bollywood trivia platform built for cinema lovers.

## Overview

**CineQuiz** tests users' knowledge across generations of Indian cinema—from iconic dialogues in classics like *Sholay* to modern blockbusters like *Pathaan* and *Jawan*. Users can select specialized categories, play against a countdown timer, take on daily dialogue challenges, and track their scores.

Live Demo: [https://dhruvipaswala0407.github.io/QUIZ/](https://dhruvipaswala0407.github.io/QUIZ/)
---

## Features

- **Multiple Trivia Categories:**
  - 💃 Bollywood Retro (70s & 80s Classics)
  - 📼 90s Nostalgia
  - 💥 Blockbusters & Action (100 Crore Club)
  - 🌟 Actors & Actresses
  - 🎶 Music & Lyrics
- **Timed Challenges:** Dynamic quiz interface featuring real-time countdown timers and live progress bars.
- **Daily Challenge:** A featured daily dialogue and film puzzle updated regularly.
- **Instant Results & Badges:** Instant scoring feedback, correct-answer reviews, and performance badges.
- **Leaderboard:** Compete and benchmark scores against fellow movie buffs.
- **Responsive UI:** Optimized for desktop, tablet, and mobile screens.

---

## How It Works

1. **Choose Category:** Browse and pick a favorite movie era or theme.
2. **Start Quiz:** Enter the timed quiz screen with randomized/custom question sets.
3. **Answer & Score:** Select answers before the clock expires with instant visual feedback.
4. **Review Results:** Inspect final score breakdowns, earned ranks, and replay options.

---

## Tech Stack

- **HTML5:** Semantic site structure
- **CSS3 / Bootstrap / Icons:** Responsive design and modern cinema-themed styling
- **JavaScript (ES6):** Timer mechanics, question data management, state tracking, and score calculations
